The search order

Four passes, in this exact sequence

The engine never scans 0000 → 9999 first. It exhausts the patterns humans actually pick, in order of documented likelihood, before falling back to a full sweep.

  1. 01

    Verified top 20

    PINs like 1234, 0000, and 1212 — ranked from real-world leaked-PIN frequency studies.

  2. 02

    Extended common set

    Documented but unranked patterns: repeat digits, birth-year-shaped numbers, calendar dates.

  3. 03

    Structural patterns

    Sequences (2345), repeated pairs (XYXY), and every likely birth year from 1940–2015.

  4. 04

    Full brute force

    Only if nothing above matches — every remaining value from 0000 to 9999, in order.
