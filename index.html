The actual search order

Four passes. Always this order.

This is a real sequence, not a design flourish — the script never scans 0000 → 9999 first. It exhausts the patterns people actually pick, ranked by how often they show up, before falling back to brute force.

  1. 01

    Verified top 20

    1234, 0000, 1212 — pulled straight from real leaked-PIN frequency studies.

  2. 02

    Extended common set

    Documented but unranked patterns: repeats, keyboard-adjacent digits, calendar-shaped numbers.

  3. 03

    Structural patterns

    Sequences like 2345, repeated pairs like 7171, and every plausible birth year from 1940–2015.

  4. 04

    Full brute force

    Only if nothing above hits — the remaining values from 0000 to 9999, in order.
